# Project Images

Place your project screenshots and images in this folder.

## Image Naming Convention

### Featured Projects:
- `final-year-project.jpg` - Main thumbnail image
- `final-year-project-1.jpg`, `final-year-project-2.jpg`, `final-year-project-3.jpg` - Gallery images

- `residence-management.jpg` - Main thumbnail image
- `residence-management-1.jpg`, `residence-management-2.jpg`, `residence-management-3.jpg`, `residence-management-4.jpg` - Gallery images

- `booking-app.jpg` - Main thumbnail image
- `booking-app-1.jpg`, `booking-app-2.jpg` - Gallery images

### Learning Projects:
- `xo-game.jpg` - Main thumbnail image
- `xo-game-1.jpg` - Gallery image

- `qr-generator.jpg` - Main thumbnail image
- `qr-generator-1.jpg` - Gallery image

## Notes
- Images will automatically fallback to placeholders if not found
- Supported formats: JPG, PNG, GIF, WebP
- Recommended size for thumbnails: 400x300px or similar aspect ratio
- Gallery images can be any size, but will be displayed responsively
